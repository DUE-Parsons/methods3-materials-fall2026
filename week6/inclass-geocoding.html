Geocoding Example

  1. We will geocode an excerpt of the 40,329 applications for a license to sell tobacco in New York City since 1998.
  2. First you need to make sure there is an address column with building number and street in one field.
  3. In Excel, open license_applications/tobacco_excerpt.csv and create a street address field from these columns: "Building Number", "Street", "City", "State", and "Zip". You can use the CONCATENATE function to do this.
  4. Open QGIS and install the All Geocoders at Once plugin.
  5. Drag and drop the tobacco_excerpt CSV you edited.
  6. In the new Plugins > All Geocoders at Once dropdown, select Geocode by any service.
  7. In this dialog:
    1. Select the version of tobacco_excerpt layer.
    2. Set address field and set geocoder to Esri (ArcGis)
    3. Click Geocode
  8. Add a baselayer using QuickMapServices to see where the geocoded points are, confirm they're in reasonable places
