Heatmaps

Using the Low Income Housing Tax Credit (LIHTC) Development points layer, add a heatmap of low-income rental properties created through the LIHTC program in NYC.

  1. Add the Low Income Housing Tax Credit (LIHTC) csv to QGIS and map the points using longitude (x field) and latitude (y field). Ensure li_units is added as an integer.
  2. Add the Borough Boundaries shapefile.
  3. Use Select by Location to select the LIHTC buildings in New York City.
  4. Export the LIHTC Listings data with 2263 as the CRS.
  5. Search for Heatmap (Kernel Density Estimation) in the QGIS search box.
  6. Weight the heat map based on the number of affordable units in the building. Set Weight from field to your numeric li_units field.
  7. Set the radius to 2000 feet.
  8. Set the rows to 3000. This is the number of rows of pixels in the resulting raster. The columns should update automatically.
  9. Style the output raster with a Singleband Pseudocolor render type and select a color ramp.
  10. Create a few more heatmaps with varying radii and resolution (rows and columns).
