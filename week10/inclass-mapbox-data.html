In-class Exercises

Add your own data to a Mapbox style

  1. Download today's data and unzip it. The Borough Boundaries shapefile should be inside it.
  2. Zip up the borough boundaries or airbnb listings.
  3. In your Mapbox style, add a new custom layer and click Upload data. Select the zip file you just made to upload it.
  4. Wait for the data to process and select it.
  5. Style the new layer.
