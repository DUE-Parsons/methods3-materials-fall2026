In-class Exercises

Select by Location

  1. Download this class's data.
  2. Open the Borough Boundaries shapefile in QGIS.
  3. Open the Public School Locations shapefile in QGIS.
  4. Let's select schools in the Bronx a few different ways:
    1. Select by location:
      1. Use select features by single click (tool) to select the Bronx.
      2. Use select by location to select school features in the Bronx.
      3. Deselect the features.
    1. Select by expression:
      1. Use select by expression to select school features where the Location_C field starts with X. The expression you use should be left("Location_C", 1) = 'X'.
  5. Export the selected school features to their own shapefile.
